# 表格规范

> MoneyNote 前端表格（ProTable / `BaseProTable`）列对齐、列宽与数字展示的统一规范。
> 所有列表页、统计报表统一按本文档执行。

## 1. 总原则

1. **文本类默认左对齐**（名称、备注、分类名等）
2. **数值类默认右对齐，并加等宽数字**（金额、数量、笔数）
3. **状态、布尔值、图标、头像等短小元素默认居中**
4. **操作列居中**
5. **同一列所有单元格用同一条对齐规则**，不要按每个单元格的内容长度逐格判断
6. **列宽由数据重要性、内容长度、页面布局决定，与对齐方式无关**

> 对齐看的是「数据语义」，不是「字符串长度」。
> 例如账户编号 `000123` 虽由数字组成，本质是标识符，应按文本左对齐，而非数值右对齐。

## 2. 对齐规则

| 数据类型 | 示例 | 对齐 | 说明 |
| --- | --- | --- | --- |
| 文本 | 名称、备注、分类名 | 左对齐 | 符合自然阅读习惯 |
| 数字 | 金额、数量、交易笔数 | 右对齐 | 便于比较大小、观察位数 |
| 日期/时间 | 交易日期、创建时间 | 左对齐 | 便于按时间顺序阅读 |
| 状态 | 已完成、待处理、已取消 | 居中 | 状态短小，便于扫描 |
| 布尔值 | 是/否、启用/禁用 | 居中 | 两种状态需快速辨认 |
| 操作按钮 | 编辑、删除、查看 | 居中 | 便于集中操作 |
| 序号 | 1、2、3 | 居中 | 标识行次 |
| 图标/头像 | 分类图标、用户头像 | 居中 | 视觉元素适合居中 |

> 上表是默认规则，非绝对限制，可结合列宽、内容长度、页面布局微调。

### 账单表格示例

| 账单名称 | 日期 | 金额 |
| --- | --- | --- |
| 午餐 | 10-12 | ¥35.00 |
| 房租收入 | 10-12 | ¥4,500.00 |
| 购买电脑 | 10-13 | ¥6,999.00 |

名称、日期左对齐，金额右对齐。即使每列各单元格长度不同，整列规则也保持一致。

## 3. 列宽规则

| 列类型 | 宽度策略 | 对齐 |
| --- | --- | --- |
| 序号 | 固定窄宽度 | 居中 |
| 日期 | 固定或最小宽度 | 左对齐 |
| 金额 | 固定或适度弹性 | 右对齐 |
| 名称 | 弹性宽度 | 左对齐 |
| 备注 | 弹性宽度，必要时截断 | 左对齐 |
| 操作 | 固定宽度 | 居中 |

- 账单名称可能 2 个字也可能 30 个字：让「名称」列占剩余空间，而不是按每行文字长度改列宽。
- 备注等长内容优先 `ellipsis` + `tooltip` 悬浮看全量；需要完整上下文时进详情页。
- ProTable 中弹性列直接不设 `width`（由表格分配）；短元素 / 固定内容列设 `width`。

## 4. 数字列特殊处理

1. **右对齐只是第一步**，金额/数量列还要用「等宽数字」（tabular-nums），让每个数字占相同宽度，纵向比较时小数点逐位对齐。
2. **金额统一走 `@/utils/money` 格式化，不要直接渲染后端的最小单位值**：
   - 固定小数位：`formatAmount(value, decimalPlaces)`
   - 去末尾零：`formatAmountDisplay(value, decimalPlaces)`
   - 带货币符号：`formatMoney(value, decimalPlaces, symbol)`
   - 小数位按币种 `decimalPlaces` 取，不硬编码「两位小数」。
3. 金额以最小货币单位（整数分）存 Long，展示时才换算，见 `src/utils/money.js` 顶部注释。

### 等宽数字

`font-variant-numeric: tabular-nums;` 让每个数字占相同宽度，纵向比较时小数点逐位对齐。
项目里已封装为共享样式 `useTableStyles().styles.numericCell`（定义在 `src/utils/tableStyles.js`），列上只需 `className: styles.numericCell`。

## 5. 代码落地（ProTable 列配置）

项目统一用 `BaseProTable`（已内置 `bordered` / `rowKey="id"`）：列的 `align` 控制对齐，`className` 负责等宽数字，`render` 负责格式化。

```js
import { useTableStyles } from '@/utils/tableStyles';
import { formatMoney } from '@/utils/money';

// 等宽数字样式定义见 src/utils/tableStyles.js（numericCell）
// ... 组件内
const { styles } = useTableStyles();

const renderAmount = (_, record) =>
  formatMoney(record.amount, record.amountCurrencyDecimalPlaces, record.amountCurrencySymbol);

const columns = [
  { title: t('moneyFlow.fields.title'), dataIndex: 'title', align: 'left', ellipsis: true },        // 文本：左对齐
  { title: t('moneyFlow.fields.createTime'), dataIndex: 'createTime', align: 'left', width: 160 }, // 时间：左对齐
  { title: t('moneyFlow.fields.amount'), dataIndex: 'amount', align: 'right', className: styles.numericCell, render: renderAmount, sorter: true }, // 金额：右对齐 + 等宽数字
  { title: t('moneyFlow.fields.confirm'), dataIndex: 'confirm', align: 'center', width: 90 },       // 布尔：居中
  { title: t('operation'), align: 'center', width: 80, render: (_, record) => [/* 按钮 */] },       // 操作：居中
];
```

> ProTable 中 `align` 取 `'left' | 'center' | 'right'`，会同时作用到表头与单元格。
> 未写 `align` 时默认左对齐。等宽数字只需补 `font-variant-numeric`，不要在 `className` 里重复写 `text-align`。

## 6. 自检清单

- [ ] 文本列左对齐（未写 `align` 即默认，也可显式写明）
- [ ] 金额/数量列 `align: 'right'` 且带 `numericCell` 等宽数字
- [ ] 状态/布尔/图标列 `align: 'center'`
- [ ] 操作列 `align: 'center'`
- [ ] 金额经 `@/utils/money` 格式化，未直接渲染最小单位整数
- [ ] 弹性文本列用 `ellipsis`，未按内容长度逐行改列宽
- [ ] 同类列（如多个金额列）对齐规则一致
