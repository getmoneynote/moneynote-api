# 弹窗（Modal）最佳实践

> MoneyNote 前端「新增 / 编辑」弹窗的统一实现规范。所有业务弹窗一律按本文档实现，现有样板见 `src/pages/currency/`。

## 1. 核心思想

三层架构 + 受控弹窗：

```text
DataTable（列表页）
   │  持有 useModalForm 实例；按钮只调 showAdd() / showUpdate(row)
   ▼
ActionForm（业务表单）
   │  字段 + 提交逻辑，其余行为全部继承自下面两层
   ▼
BaseModalForm（统一壳）┄┄ useModalForm（状态层）
```

关键约定：

- **每个列表页一个 `useModalForm` 实例**，弹窗是受控组件，状态统一提升到页面。
- **增改复制共用同一个 `ActionForm`**，靠 `isEdit` / `isCopy` 区分模式，不复制多套表单。
- **`isEdit=true` 时 `currentRow` 一定存在**（`showUpdate(row)` 保证），业务代码不判空。
- 提交成功后 `onFinish()` 回调里 `actionRef.current?.reload()` 刷新列表。
- **禁止**直接在页面里写 `useState` 控制弹窗开关。
- **禁止**直接 `import { ModalForm }`，一律走 `BaseModalForm`。

## 2. 架构与文件职责

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 状态层 | `src/hooks/useModalForm.js` | `open / mode / currentRow` 状态与 `showAdd / showUpdate / hide` 方法 |
| 壳层 | `src/components/BaseModalForm/index.jsx` | 统一 ModalForm 公共行为（默认 `destroyOnClose` / 居中 / `maskClosable:false`） |
| 业务层 | `src/pages/<feature>/ActionForm.jsx` | 只关心字段与提交逻辑 |
| 列表页 | `src/pages/<feature>/DataTable.jsx` | 持有 `useModalForm`、触发操作、刷新 |

数据流：

```
showAdd() / showCopy(row) / showUpdate(row)
   → open=true, mode=add|copy|edit, currentRow=row
   → ActionForm 受控渲染，initialValues=currentRow
onFinish(values)
   → isEdit ? update(id, values) : create(values)
   → onFinish() → actionRef.reload()
   → return true → 弹窗自动关闭
```

## 3. 标准文件模板（完整代码）

### 3.1 `src/hooks/useModalForm.js` — 状态层

```ts
import { useCallback, useState } from 'react';

/** 弹窗模式：add=新增，copy=复制，edit=编辑 */
export type ModalMode = 'add' | 'copy' | 'edit';

/**
 * 弹窗统一状态管理：open / 模式 / 当前行。
 * 每个列表页持有自己的实例，通过 props 传给 ActionForm。
 */
export function useModalForm<TRow = Record<string, unknown>>() {
  const [open, setOpen] = useState(false);
  const [mode, setMode] = useState<ModalMode>('add');
  const [currentRow, setCurrentRow] = useState<TRow | undefined>();

  const showAdd = useCallback(() => {
    setMode('add');
    setCurrentRow(undefined);
    setOpen(true);
  }, []);

  const showCopy = useCallback((row: TRow) => {
    setMode('copy');
    setCurrentRow(row);
    setOpen(true);
  }, []);

  const showUpdate = useCallback((row: TRow) => {
    setMode('edit');
    setCurrentRow(row);
    setOpen(true);
  }, []);

  const hide = useCallback(() => setOpen(false), []);

  return {
    open,
    mode,
    isEdit: mode === 'edit',
    isCopy: mode === 'copy',
    currentRow,
    onOpenChange: setOpen,
    showAdd,
    showCopy,
    showUpdate,
    hide,
  };
}

/** ActionForm props 里 modal 的类型 */
export type ModalFormState<TRow> = ReturnType<typeof useModalForm<TRow>>;
```

> 用字符串联合 `'add' | 'edit'` 而非数字枚举：更可读、无 TS 数字枚举的坑。

### 3.2 `src/components/BaseModalForm/index.jsx` — 壳层

```tsx
import { ModalForm, type ModalFormProps } from '@ant-design/pro-components';

interface BaseModalFormProps<Values> extends ModalFormProps<Values> {
  /** 快捷开启水平布局，默认 labelCol=6 / wrapperCol=16 */
  horizontal?: boolean;
}

/**
 * 统一弹窗表单壳：所有业务弹窗统一走这里，公共行为集中管理。
 * - destroyOnHidden：关闭即销毁表单，保证每次打开都是全新状态，initialValues 才可靠
 * - centered / mask.closable=false：统一交互，防止误点遮罩丢表单
 * - horizontal：快捷开启水平布局，默认 labelCol=6 / wrapperCol=16
 * 业务可通过 modalProps / layout / labelCol / wrapperCol 覆盖这些默认值。
 *
 * 业务代码禁止直接 import { ModalForm }，一律走 BaseModalForm。
 */
export default function BaseModalForm<Values>(props: BaseModalFormProps<Values>) {
  const { modalProps, horizontal, labelCol, wrapperCol, layout, ...rest } = props;

  const computedLayout = layout ?? (horizontal ? 'horizontal' : undefined);
  const computedLabelCol = labelCol ?? (horizontal ? { span: 6 } : undefined);
  const computedWrapperCol = wrapperCol ?? (horizontal ? { span: 16 } : undefined);

  return (
    <ModalForm<Values>
      {...rest}
      layout={computedLayout}
      labelCol={computedLabelCol}
      wrapperCol={computedWrapperCol}
      modalProps={{
        centered: true,
        destroyOnHidden: true,
        mask: { closable: false },
        ...modalProps,
      }}
    />
  );
}
```

> **业务代码禁止直接 `import { ModalForm }`**，一律走 `BaseModalForm`。

### 3.3 `src/pages/<feature>/ActionForm.jsx` — 业务表单模板

```tsx
import { ProFormDigit, ProFormText } from '@ant-design/pro-components';
import BaseModalForm from '@/components/BaseModalForm';
import type { ModalFormState } from '@/hooks/useModalForm';
import { <feature>Api } from '@/api/<feature>';
import { useT } from '@/utils/i18n';

interface ActionFormProps {
  modal: ModalFormState<API.<Feature>>; // 实体类型只用于行数据，表单值类型用 CreateForm
  onFinish: () => void;
}

export default function ActionForm({ modal, onFinish }: ActionFormProps) {
  const t = useT();
  const { open, currentRow, isEdit, onOpenChange } = modal;

  return (
    <BaseModalForm<API.<Feature>CreateForm>
      title={isEdit ? t('<feature>.action.edit') : t('<feature>.action.add')}
      open={open}
      onOpenChange={onOpenChange}
      initialValues={currentRow}
      onFinish={async (values) => {
        if (isEdit) {
          // isEdit 为 true 时 currentRow 一定存在（showUpdate 保证），无需判空
          // 注意：只提交契约允许的字段（见「常见坑」#3）
          await <feature>Api.update(currentRow.id, {
            name: values.name,
            usdRate: values.usdRate,
          });
        } else {
          await <feature>Api.create(values);
        }
        onFinish();
        return true;
      }}
    >
      {/* 字段 label 一律用 t()，i18n key 加到 locales */}
      <ProFormText name="name" label={t('<feature>.fields.name')} rules={[{ required: true }]} />
      <ProFormDigit name="usdRate" label={t('<feature>.fields.usdRate')} rules={[{ required: true }]} min={0} />
    </BaseModalForm>
  );
}
```

### 3.4 `src/pages/<feature>/DataTable.jsx` — 列表页接线

```tsx
import { useRef } from 'react';
import type { ActionType } from '@ant-design/pro-components';
import BaseProTable from '@/components/BaseProTable';
import { useModalForm } from '@/hooks/useModalForm';
import ActionForm from './ActionForm';

export default () => {
  const modalForm = useModalForm<API.<Feature>>();
  // actionRef 直接 useRef，不需要 umi model 包一层
  const actionRef = useRef<ActionType>(null!);

  const addHandler = () => modalForm.showAdd();
  const updateHandler = (record: API.<Feature>) => modalForm.showUpdate(record);

  return (
    <>
      <BaseProTable
        /* rowKey='id'、隐藏搜索按钮等公共行为由 BaseProTable 统一管理，其余属性按页传入 */
        actionRef={actionRef}
        toolBarRender={() => [
          <Button type="primary" onClick={addHandler}><PlusOutlined />{t('add')}</Button>,
        ]}
      />
      <ActionForm
        modal={modalForm}
        onFinish={() => actionRef.current?.reload()}
      />
    </>
  );
};
```

## 4. 新增一个弹窗的步骤

1. **确认 API 就绪**：`src/api/<feature>.js` 有 `list / create / update / delete`（`update/delete` 为 `(id, body)` / `(id)` 形态）。没有则先手写补上。
2. **列表页**：`useRef(null)` 建 `actionRef`；`useModalForm()` 建 `modalForm`；新增/编辑按钮分别调 `showAdd()` / `showUpdate(record)`。
3. **写 ActionForm**：复制 §3.3 模板，字段对照契约，label 走 `t()`。
4. **补 i18n**：`locales/zh-CN/<feature>.js` 和 `en-US/<feature>.js` 加 `<feature>.action.add` / `<feature>.action.edit` 及所有字段 key。
5. **自检**：见 §5 硬性规则。

## 5. 硬性规则（自检清单）

- [ ] 弹窗全部用 `BaseModalForm`，源码里没有 `import { ModalForm }`
- [ ] 水平布局用 `horizontal` prop，不手写 `layout / labelCol / wrapperCol` 三行（默认 6/16 不满足再单独覆盖）
- [ ] 提交数据对齐 `<Feature>CreateForm` 的字段，不提交实体全量（实体字段只用于行数据）
- [ ] create/update 字段完全相同时，提取 `toPayload()` 共用，不写两遍
- [ ] `isEdit` 分支内不判空 `currentRow`（`showUpdate` 保证其存在）
- [ ] `actionRef` 用 `useRef`，不通过 `useModel` 包一层
- [ ] 文案全部走 `useT()`，无硬编码中文
- [ ] `onFinish` 返回 Promise（`await` API），loading / 错误交给框架
- [ ] 没有注释掉的 API 调用、没有 `show(<...>)` 之类的死代码
- [ ] 金额字段用整数分，不用浮点

## 6. 常见坑

1. **`initialValues` 与 `destroyOnHidden` 是强耦合**：`initialValues` 只在表单首次挂载时生效。没有 `destroyOnHidden`，第二次打开编辑态会带出上一次的残留值。`BaseModalForm` 默认已开 `destroyOnHidden`，不要关掉它。
2. **`isEdit` 与 `currentRow` 联动**：`showUpdate(row)` 同时设置 `mode='edit'` 和 `currentRow=row`，所以 `isEdit=true` 时 `currentRow` 一定存在，业务代码不需要判空。
3. **path 参数直接拼接 URL**：手写 API 请求时，`update/delete` 的 `id` 直接用模板字符串拼到 URL 里（如 `` `/currencies/${id}` ``），不要用 params 对象传 path 参数。
4. **update 只提交契约允许的字段**：例如 currency 的 PATCH 契约只接受 `{ name, usdRate }`，不要把整个 CreateForm 全量丢给 update。
5. **增改共用表单时**，`currentRow` 只在 edit 分支有值，提交前判空（此时 `isEdit` 保证其存在）。
6. **文件结构**：弹窗拆成 `ActionForm.jsx`，不要全部塞进列表页；`index.jsx` 只做页面容器。
7. **create/update payload 重复**：如果两边字段完全相同，提取 `toPayload()` 函数共用，避免写两遍导致不一致。
